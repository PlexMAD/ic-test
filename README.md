# Интерактивная карта Москвы

Проект на **React + Tanstack + Zustand** с интерактивной картой (deck.gl + maplibre) и моковыми данными, перенесены в `public/api`.

## Возможности

- Отрисовка слоёв (районы/улицы/транспорт) из мокового API (`public/api/*.json`)
- Просмотр информации об объекте в drawer
- **Добавление пользовательских точек** (**Train** и **Bus**):
  - Кнопка **«Добавить точку»** → модалка с формой (только поля, используемые в инфо-дроверах)
  - После подтверждения включается режим **placing**
  - Клик по карте ставит точку
  - Точки сохраняются в `localStorage` (zustand `persist`) и не пропадают после перезагрузки
  - По клику на добавленную точку открывается тот же drawer с информацией (StationInfo/BusInfo)

## Быстрый старт

Требования: **Node.js 18+** (рекомендуется) и npm.

```bash
npm install
npm run dev
```

Откройте адрес из консоли (`http://localhost:9999`).

### Сборка/проверка

```bash
npm run build
npm run preview
npm run lint
```

## Как добавить пользовательскую точку

1. Нажмите **«Добавить точку»** в верхней панели
2. Выберите тип (**Train** или **Bus**) и заполните поля
3. Нажмите **«Далее»**
4. Кликните на карте в нужном месте — точка появится на карте
5. Перезагрузите страницу — точка останется (persist в `localStorage`)

Чтобы отменить режим постановки, используйте кнопку **«Отменить постановку»**.

## Данные (моковое API)

Моки лежат в `public/api/` и подхватываются как статические файлы.
